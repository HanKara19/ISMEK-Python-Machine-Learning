
# Smart Bill Splitter

## Project Description

Smart Bill Splitter is a beginner-friendly Python application that helps users split a restaurant bill equally among a group of people.

The program calculates the tip, total bill, and amount each person should pay.

## Features

- Accepts the original bill amount
- Calculates a tip based on a percentage
- Divides the total amount between people
- Displays results with two decimal places

## Python Concepts Used

- Variables and data types
- User input
- Type conversion
- Arithmetic operators
- f-strings

## How It Works

1. Enter the original bill amount.
2. Enter the tip percentage.
3. Enter the number of people.
4. The program calculates the total payment.
5. The final amount is divided equally.

## Example

Input:

```text
Bill amount (TL): 600
Tip percentage: 10
Number of people: 3
```

Output:

```text
Bill amount: 600.00 TL
Tip: 60.00 TL
Total amount: 660.00 TL
Per person: 220.00 TL
```

## How to Run

Run the following command from the project folder:

```bash
python smart_bill_splitter.py
```

## Limitations

- The number of people must be greater than zero.
- Users must enter valid numeric values.
- Input validation is not included in this beginner version.
